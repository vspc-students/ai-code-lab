## Գիտական նորույթը

"AI-գեներացված կոդի հետ աշխատանքի ծրագրավորման կոմպետենտության բազմաչափ  գնահատման մեթոդ", որը համադրում է կոդի ընկալումը, սխալի հայտնաբերումն ու ուղղումը, կոդի ադապտացումը, օպտիմալացումը և բացատրության հստակությունը՝ միաժամանակ գրանցելով առաջադրանքի բարդությունը, պատասխանման ժամանակը և գնահատման վստահությունը։

Գնահատման համակարգի գիտական վավերացում

Համակարգի գիտական հիմնավորվածությունը նախատեսվում է գնահատել բազմաղբյուր վավերացման մեթոդաբանությամբ՝ համադրելով արհեստական բանականության կողմից տրված գնահատականները, ծրագրավորման փորձագետների անկախ գնահատականները և ավտոմատացված unit tests-երի արդյունքները։ Այս մոտեցումը հնարավորություն կտա ուսումնասիրել, թե որքանով է AI-ի վրա հիմնված գնահատման մեխանիզմը համապատասխանում մարդկային փորձագիտական գնահատմանը և ծրագրի օբյեկտիվ ֆունկցիոնալ ճիշտությանը։

Վավերացման ընթացքում նույն ուսանողական լուծումները կգնահատվեն երեք անկախ աղբյուրների միջոցով՝ AI գնահատող, մարդկային փորձագետներ և ավտոմատացված թեստեր։ Ստացված արդյունքների համաձայնությունը և տարբերությունները կվերլուծվեն վիճակագրական մեթոդներով՝ գնահատելու համակարգի հուսալիությունը, հետևողականությունը և գնահատականների հիմնավորվածությունը։

Այս փուլը թույլ կտա ոչ միայն ստուգել համակարգի գնահատման ճշգրտությունը, այլև բացահայտել այն իրավիճակները, որտեղ AI-ի գնահատականը կարող է տարբերվել փորձագետի կամ օբյեկտիվ ավտոմատ թեստի արդյունքից։ Այդ տարբերությունները նույնպես կդիտարկվեն որպես հետազոտական արդյունք՝ AI-ի վրա հիմնված ծրագրավորման կոմպետենտության գնահատման ուժեղ և թույլ կողմերի բացահայտման համար։

## CSS ավելացում

Բոլոր հիմնական տեսողական փոփոխությունները սկսեք `assets/theme.css`-ից.

- `--acl-primary` — հիմնական գույն
- `--acl-primary-hover` — hover
- `--acl-bg` — էջի ֆոն
- `--acl-surface` — քարտերի/մակերեսների ֆոն
- `--acl-border` — եզրագծեր
- `--acl-radius` — ընդհանուր անկյունների կլորություն
- `--acl-button-radius` — button-ների անկյուններ
- `--acl-shadow` — ստվեր
- `--acl-sidebar-width` — աջ/ձախ sidebar-ի լայնություն
